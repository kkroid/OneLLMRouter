# OneLLMRouter v1.5.2 小版本计划

> 基线：v1.5.1（已发布）
>
> 目标：修复 Claude Code 对带 `[1m]` 模型名的标准化问题，并让桌面托盘反馈实际发生的上游重试。

## 版本范围

1. Anthropic 客户端模型使用不含方括号的客户端别名，通过 `upstream_model` 映射到上游要求的完整模型名。
2. Core 在 Retry 策略确定继续尝试时，通过 `/health` 暴露正在重试的客户端模型。
3. 托盘在存在重试活动时使用黄色图标，并在 tooltip 和菜单状态显示模型；重试结束后的展示最多保留 3 秒，便于轮询捕获。

本版本不改变重试次数、等待时间、自动故障转移、模型发现优先级或任何客户端配置管理范围。

## 验收

- Claude Code 使用 `ds/deepseek-v4-flash-1m` 时，Router 向 DeepSeek Anthropic 线路发送 `deepseek-v4-flash[1m]`。
- 不可重试的单次失败不会显示为“正在重试”。
- 并发重试显示去重后的模型列表，全部完成后托盘恢复绿色健康状态。
- Go、Qt 编译和测试通过，Setup 产物版本为 1.5.2。
